# Espluque user quick start

## Start an analysis

1. Launch Espluque.

2. Drag a file into the application window.

3. Wait for the analysis to complete.

A new tab is created at the top of the interface for each analyzed file.

## Navigate through the results

Inside the file tab, the left panel contains the available results:

- the upper links open property lists produced by grabbers;

- the lower links open viewers compatible with the detected file format.

Select a link to display its content in the main area of the tab.

## Follow the analysis

The log area remains visible at the bottom of the interface.

It shows the main analysis steps, detected concepts, activated contributions and possible errors.

## Analyze another file

Drag another file into the application.

Each file is analyzed in its own tab, so several results can remain open at the same time.
